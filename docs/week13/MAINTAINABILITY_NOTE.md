# Maintainability note

The foundation has clear seams: Flutter models/services/providers isolate presentation from transport, Laravel controllers enforce workflow rules, and Eloquent migrations define durable state. Bounded GET retries apply only to transient network/server failures; business-rule 4xx responses are shown without retry. Scheduled commands are idempotent for a given week and avoid duplicate open escalations.

Sanctum bearer authentication, role checks, assignment scoping, and adverse-request tests now protect the API. Remaining production gaps include account lifecycle (password reset, MFA, disabling accounts), a complete audit history for manual status changes, explicit data-retention controls, API pagination, MySQL-backed integration coverage, notification delivery through a queued provider, and centralized structured telemetry. Do not expose real student data over HTTP; production deployments require HTTPS and deployment-specific secret, storage, and monitoring controls. The stalled threshold is configurable (`AUTOMATION_STALLED_AFTER_DAYS`, default 14), while the schedule remains in the Laravel console kernel.
